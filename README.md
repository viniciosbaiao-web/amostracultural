# 📊 Calculadora de Média Escolar em Python

Este projeto foi desenvolvido como atividade prática para exercitar a lógica de programação em Python e as boas práticas de documentação de projetos no GitHub.

## 🎯 Objetivo do Projeto
O script tem como objetivo automatizar o cálculo da média aritmética de um aluno a partir de duas notas, informando automaticamente se ele está aprovado, em recuperação ou reprovado.

## ⚙️ Funcionalidades
* **Entrada de dados:** Recebe duas notas via terminal com suporte a números decimais.
* **Validação de intervalo:** Aceita apenas notas válidas entre 0 e 10.
* **Tratamento de erros:** Impede que o programa quebre caso o usuário digite letras ou caracteres inválidos.
* **Classificação automática:** Exibe a média final e o status do aluno (Aprovado, Recuperação ou Reprovado).

## 🚀 Como Executar o Código

### Pré-requisitos
* Ter o **Python 3** instalado em sua máquina.

### Passo a passo
1. Clone este repositório ou baixe o arquivo `script.py` para o seu computador.
2. Abra o terminal (ou prompt de comando) na pasta onde o arquivo foi salvo.
3. Execute o comando abaixo:

```bash
python script.py
```

4. Siga as instruções exibidas no terminal e digite as notas solicitadas.

## 💻 Exemplo de Uso

```text
=== Calculadora de Média Escolar ===
Digite a primeira nota (0 a 10): 8.5
Digite a segunda nota (0 a 10): 7.0

Sua média final foi: 7.8
Situação: APROVADO! Parabéns.
```
